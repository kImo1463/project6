Event Ticketing App

#Overview

This project is a user-friendly event ticketing application that allows users to seamlessly browse, purchase, and manage event tickets. The platform simplifies event discovery and provides an intuitive interface for ticket transactions.

#Features

User Authentication: Register, login, logout, and password recovery.

Event Browsing: Search and filter events by category, location, and date.

Ticket Purchase: Secure checkout process for purchasing tickets.

Order Management: View purchase history and manage tickets.

Event Management: Organizers can create and manage events.

Mobile-Friendly Design: Responsive interface for mobile and desktop users.

#Tech Stack

Backend: Django (Python)

Frontend: HTML, CSS, JavaScript 

Database: SQLite

Authentication: Django Authentication System
